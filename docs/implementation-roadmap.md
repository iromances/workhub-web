# WorkHub 前端实施路线

## 1. 实施目标

前端第一阶段要交付一套可用的后台控制台，支持从待整理箱到正式工作项的完整操作闭环，而不是只做静态展示。

## 2. 里程碑

### M1. 工程基线

- 初始化 Vue 3 + TypeScript + Vite 工程
- 接入路由、状态管理、请求层、布局骨架
- 建立统一主题、通用表格、通用搜索栏、通用详情抽屉

### M2. 登录与基础框架

- 登录页
- 权限拦截
- 首页布局
- 菜单与路由骨架
- 用户信息与退出

### M3. 主业务 MVP

- 项目列表/详情
- 迭代列表/详情
- 版本列表/详情
- 工作项列表/详情
- 跟踪记录面板
- 状态流转动作面板

### M4. 收件与整理

- 企微待整理箱
- 人工新建入口
- 粘贴文本整理入口
- AI 建议结果确认页

### M5. 可视化与增强

- 看板页
- 首页工作台
- 到期提醒与通知中心
- 常用筛选和保存视图
- 支付配置管理页
- AI 配置页，用于维护 AI 接入通道、业务 useCase、模型参数、Schema 和提示词模板
- 业务监测页，用于维护业务线 XXL-JOB 数据库名、查看 XXL-JOB Admin 报表快照统计并在详情中按日期区间快速定位失败 Job，MQ 消息监测入口预留
- 系统预警页，用于独立查看系统异常和慢 SQL，并按业务线、环境、服务、级别、错误消息和时间范围查询分类事件汇总与明细；系统异常的汇总和最近事件使用二级页签分开展示，事件明细不展示异常类型列，并提供按当前行错误消息全局精确删除的行内入口；列表每页支持 20、50、100、500、1000 条；有权限用户可通过独立弹框输入错误消息，全局异步执行模糊“删除”或“删除&过滤”，所有清理任务均不使用页面查询条件且不自动刷新列表；提交后右上角任务通知持续更新后台状态，终态后倒计时 10 秒关闭，也支持随时手工关闭（仅停止前端轮询，后台任务继续）；关注业务线支持整条业务线或指定子系统两种范围，过滤规则在独立页签维护，慢 SQL 不发送站内信
- MCP 页，用于统一维护堡垒机、数据库只读查询目标、数据库目标堡垒机关联、服务器白名单服务和允许 AI 读取的白名单目录

## 3. 页面优先级

必须先做：

- 登录页
- 项目列表
- 工作项列表
- 工作项详情
- 待整理箱

随后补齐：

- 迭代管理
- 版本管理
- 看板
- 工作台

## 4. 开发顺序约束

1. 先接入统一布局和请求层，再做业务页面。
2. 先完成列表与详情基本闭环，再做看板和工作台。
3. 先完成人工录入和人工确认，再接 AI 结果确认。
4. 先按后端契约开发，不允许为了提速自行发明字段。

## 5. 验收基线

1. 用户可以登录并进入后台。
2. 用户可以查看项目、工作项、待整理箱。
3. 用户可以创建工作项、修改负责人、写跟踪记录、执行状态流转。
4. 用户可以查看企微原始内容和 AI 整理建议，并确认生成正式工作项。
5. 列表、详情、看板展示出的状态和后端一致；需求管理页可以暂停需求、恢复到暂停前状态，并在详情中查询对应修改历史。
6. 运维菜单下可以进入业务监测页、系统预警页和 MCP 页；业务监测页支持维护业务线 XXL-JOB 数据库名、查看 XXL-JOB Admin 报表快照统计、在详情弹框按日期区间快速定位失败 Job，并通过站内信查看定时预警；系统预警页支持按系统异常、慢 SQL、关注业务线、过滤规则四个页签查询和维护，事件可按错误消息模糊查询、选择每页 500/1000 条；事件明细不展示异常类型列，支持按行错误消息全局精确删除，也可在权限控制下通过独立弹框输入错误消息，全局异步执行模糊删除或删除并过滤；所有清理任务均不使用页面筛选且不自动刷新页面数据，任务通过右上角持久通知更新状态，在终态后倒计时 10 秒关闭并支持随时手工关闭；关注业务线可选择整条业务线或指定子系统，慢 SQL 独立统计且不发送站内信，过滤规则从下一轮采集生效；MQ 消息监测入口预留；MCP 页可以查询、新增和修改堡垒机，数据库目标开启堡垒机后从已启用配置中选择，同时支持按业务线、环境维护数据库只读查询目标、服务器所属系统多选、服务器白名单服务和允许 AI 读取的白名单目录，并能查看 MCP 审计记录。
7. 系统管理菜单下可以进入 AI 配置页，维护 AI 接入配置和 AI 任务 useCase 配置。


MCP 的目录读取白名单复用已有 allowedLogPaths 字段，日志文件、目录浏览及文本文件读取共用；服务器新建默认 /mnt，清空则禁止按路径读取。其他目录须用户明确授权后由有资源维护权限的用户添加；保存时对新增且不在原授权范围或 /mnt 内的目录显示“明确授权并保存”确认，取消不发送保存请求。AI 不自行扩展。

### 完成目标契约实施（2026-11-04）

任务规格新增completionTargets，按业务线/环境成对保存，属于原任务scopes且仅允许TEST/PROD。包含DEPLOYMENT或VERIFICATION时必须显式提供非空、无重复目标；普通报告/代码/独立实测任务不要求发布目标，也不能夹带无作用的目标。分派界面不默认选择任何完成目标；缩小范围或移除相关产物会清理失效选择。目标随任务与每轮运行规格冻结，并参与请求幂等摘要。
